
# NEXORA – E-Commerce Website

NEXORA is a responsive e-commerce website built using HTML, CSS, and JavaScript. It provides a simple shopping experience with product browsing and cart management.

## Links

- **GitHub Repository:** [NEXORA-Ecommerce](https://github.com/09KhushiMathur/NEXORA-Ecommerce)
- **Live Demo:** [View NEXORA Website](YOUR_NETLIFY_LINK_HERE)

## Features

- Responsive website layout
- Product listing and browsing
- Add products to cart
- Increase and decrease product quantities
- Remove products from cart
- Cart data stored using Local Storage
- Product data managed through JSON

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Vite
- JSON
- Local Storage

## Getting Started

### 1. Clone the repository

git clone https://github.com/09KhushiMathur/NEXORA-Ecommerce.git

### 2. Navigate to the project folder

cd NEXORA-Ecommerce


### 3. Install dependencies

npm install

### 4. Start the development server

npm run dev

Open the local URL displayed in your terminal to view the website.
